# Resumo consolidado

## Fluxo de caixa

Ferramenta que controla entradas e saídas financeiras.

## Fluxo de caixa projetado

Utilizado para planejamento financeiro.

## Fluxo de caixa realizado

Utilizado para controle e comparação com o planejado.

## Indicadores principais

* Liquidez corrente
* Capital de giro
* Prazo médio de pagamento
* Saldo de caixa
* Geração operacional de caixa

## Aplicação em BI

Esses indicadores podem ser transformados em dashboards no Power BI para acompanhamento gerencial.
